# 图片材料与交付记录

取材时同时检查信息源原图和正文。优先选择与论述直接有关、使用条件明确的照片、论文图表、官方界面或自有作品；记录具体来源，署名不能代替许可。没有可用原图与尚未检查原图分开记录。

图标、网页、输入法皮肤、动物识别和作品赏析须能看见所分析的实际对象。不能用生成图或通用卡片替代该对象。图片和正文中的对象、版本、日期一致；真实统计与实验图来自实际输入/输出，不能由图像模型编造数据证据。

解释性示意可在确有信息用途时使用，不冒充真实对象或数据；公开图注、alt 和画面不标“AI 生成”“AI 辅助生成”“AI-generated”，生成方式写入私有 images 记录。科学计算图使用计算/绘图工具；不将代码绘制的同款流程卡片设为所有栏目默认补图方式。

每张成稿图有真实文件、可解码内容、正文引用、具体 alt 和关联图注。公开图注只写三项：以“图：”开头的简短图题（一句，以句号结束）、作者或机构、带链接的来源名称，链接指向该图自己的出处页，例如“图：长毛型。Remigiusz Józefowicz，[Wikimedia Commons](该图文件页)”。AI 生成的图和代码绘制的图只写图题。画面描述、许可名称与链接、改动说明（缩放、转格式、裁剪）、与所述研究的关系、实际选图、放弃原因、许可证据和文章绑定写入私有 images/verification 记录，不出现在公开图注。旧图替换沿用稿件身份和版本，不伪造历史凭据。

每张正文图都要有内容用途。最少张数按本篇线上配置（配图规则的 minimum）及作者明确调整：多数栏目至少一张，品种与物种档案栏目至少三张不同的照片；同一张图重复使用只算一张。可按选题与本篇明确要求增加，不把某个历史批次的张数自动泛化到别的栏目。没有取得足够的图片时保留待完成状态，不交稿；不以站标、页脚、无关装饰图或自绘示意充数。

交付检查按上面的图注格式逐条核对：图题之后只能接作者和带链接的来源，许可、说明、引用标号都会被拒；需要真实对象的栏目，每条图注都必须带作者和来源链接。

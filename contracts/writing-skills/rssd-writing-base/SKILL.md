# RSSD 共同写作规则

这是本次写作开始前从线上 Center 取得的默认基线。先按基线理解工作空间、栏目和成稿要求，再叠加作者本篇明确的任务要求或本地调整。设备的旧技能、旧模板和旧 brief 不得直接替代这份初始状态。当前用户明确指令优先，调整仅作用本篇；保留基线版本、来源和调整记录，不自动回写默认配置。
选题与栏目对应，实际阅读原文再写；搜索命中、RSS 摘要、提交列表和文件名不等于已读正文。材料不足时继续取得可读材料或选择能完成的问题，不能用两段入口说明、摘要或未完成的核心内容冒充完整文章。核验随取材和写作完成，正文与作者备注按项目协议一次分开提交。
文章围绕具体读者问题给出事实、解释、方法或步骤，标题准确，段落推进信息。篇幅由本篇明确要求及内容决定，不预设所有栏目统一字数，不把备注、来源清单或 JSON 计入正文篇幅。
正文事实附近使用参考文献序号，文末列可回查的题录；只著录实际核实的作者、题名、日期、版本及链接，不编造字段。需要当前步骤、费用或有效期时继续读取现行实施文件与官方入口。
图片须与正文承担的信息用途对应，图片真实可读、已经导入并与本篇绑定，不能用站标或页脚图标计数，不用任意装饰图凑数。图注保留必要来源、署名、许可及示意身份；每张图用20–60字具体alt描述画面。图片制作与选择过程写入私有images备注。
成稿包含与正文有关的正文图；具体数量由栏目配置和本篇明确要求决定。先检查信息源实际图片，不自动用同款流程卡片兜底；示意不能代替读者需要看见的真实对象。真实数据图按实际数据和可复现工具绘制。配图细则见随本篇冻结的 images.md。
本地偏好可以调整语气、篇幅和展开方式；作者本篇明确任务还可调整图片方案，均需在取得线上基线后单独记录。不能把缺失流程或未取得图片自动解释为作者调整。发布权限、身份、去重、版本及回执沿用既有流程。

配图时读取 [图片材料与记录](references/images.md)，只使用本篇解析结果所选的文体和领域规则，不加载全部栏目。

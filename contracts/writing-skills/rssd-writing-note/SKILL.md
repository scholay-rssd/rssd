# 笔记

笔记是一篇独立的短作品，有自己的页面、标题和标签。读者先看图，再读几段短文字，读完就得到一个具体看点。本规则只管笔记的形式：凡是共同规则和文体规则里关于篇幅、结构和参考文献排法的要求，与本规则冲突时按本规则；关于事实、来源、图片真实性和公开/私有分工的要求照常适用。

只写一个看点，从本栏要素中挑读者最想知道的那一项，不要把长文的各节都压缩进来。看点要具体，比如一种猫的耳朵为什么折、一张图标里线宽怎样统一、一条判决改变了什么做法，而不是“全面了解某某”。

图片承担主要信息。按阅读顺序排列，每张图讲一件事，第一张就要让人认出主题。图要能看清所说的对象；需要真实对象的栏目不能用示意图代替。图注、alt 和私有 images 记录沿用共同规则。卡片页面另行生成，不要在图片上叠字，也不要把文字排成卡片。

文字只写看懂图片所需的事实和一个判断。用几段短段落，不加小标题，不写开场铺垫、结尾总结、“你学会了吗”之类的互动句，也不用列表凑数。笔记短是体裁，不是材料不足的理由：取材和核验与长文相同，没读到原文的事不写。

来源放在文末，写成一两条可回查的出处，带链接；只在需要区分不同来源时才加序号。#标签是作品字段，由作者或工具另行设置，不写进正文。

## 由长文改写的笔记

任务说明本篇改写自某篇长文时，事实只取自那篇长文的指定修订及其来源。从中选一个看点重新写，不按原文顺序删减成摘要。新增的事实要有新的来源，并记入 verification。原文的图可以沿用，图注和许可记录随图带过来。两篇作品之间的链接由程序生成，正文里不写“原文见”“详见长文”。

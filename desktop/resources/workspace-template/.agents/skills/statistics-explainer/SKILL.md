# 统计学写作

先明确读者问题、观测单位和要估计的量，再选公式。用一个可算的小例子贯穿正文，说明每个数字来自哪里。样本标准差描述个体分散，标准误描述统计量在重复抽样中的变化；样本量、重复次数和独立样本数不能互换。

公式旁解释符号与单位，紧接一次带入计算。表格和图使用同一组结果，坐标、分母、置信水平和样本量明确。理论值与模拟值分别命名，显示合理精度；不要把随机波动写成方法错误，也不把可重现等同于外部有效。

写实操时实际运行：记录数据生成机制或公开数据版本、随机种子、软件版本、完整代码、输出与检查。生成数据必须注明模拟，不能写成真实人群或实验样本。图形用计算结果绘制，不用图像生成编造数据图。

解释先回答数值对原问题意味着什么，再交代对结论有影响的具体假设。相关不冒充因果，p 值不当效应大小，95%区间的长期覆盖率不改写成某个固定参数在本次区间中的95%概率。无需在末尾另列无关免责声明。

正文完成后再提炼短标题。少用“理解概念—重要意义—实际应用”的空框架；在一个算例里推进到读者能复算、能判断结果。按当前委派范围写回子弹笔记，不越界改其他行；写作研究与格式校验分开，不增加 AI 审稿门槛。

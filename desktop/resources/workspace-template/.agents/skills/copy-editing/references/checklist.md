# 集中修订检查清单

在一次修订中按需检查，不逐项重写全文。完成后只复核实际改动及其上下文。

- 读者问题、主要判断和段落关系清楚；没有重复引言与无信息总结。
- 数字、单位、日期、专名、引文和出处保持准确；因果、实验对象与适用条件没有扩大。
- 新增事实有实际支持，缺资料不编造，也不借修辞变成确定结论。
- 术语、指代和句子可理解；保留作者有意的语气与个人表达。
- 标题覆盖实际正文，不承诺未提供的信息。
- 只修改授权范围，人工保护、来源链接、代码、路径及非目标段落保持完整。
- 只有明确要求营销时才检查收益、关系披露与行动入口；不默认添加煽情、广告或零风险承诺。

没有具体遗留问题就结束，不输出整套检查报告；用户要求审稿报告时另按其范围交付。

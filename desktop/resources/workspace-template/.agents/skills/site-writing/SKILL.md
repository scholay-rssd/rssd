# 当前空间写作

以任务提供的领域、读者问题和作者材料为准，不把其他空间的栏目与品牌带入当前文章。区分事实、观点、计划与亲身经历；关键数字、日期、因果与现行步骤核对原文，不能编造来源或实测。

在文章板里按本轮委派修改节点，保留稳定 ID、来源、人工锁和非委派内容。新稿一次成文，直接将公开 blocks 与内部 blockNotes 分开写入 JSON，不在写完后通过二次校对迁走说明。正文篇幅单独满足要求，内部备注另留预算；只有作者要求改稿时才集中修订。按需配图，不强制数量。作者保存与公开发布使用现有版本检查和确认流程。

正文与作者备注的分工遵循当前项目写作协议，旧模板与 brief 中冲突的声明要求不再执行。事实核查是作者的义务；必要事实、证据边界、资料阅读范围、未实测及不冒充实测等检查只用于作者内部核验，记录写入对应行的 verification，整篇说明使用 internalNotes，不写成公开正文、摘要或 fields.status 的声明。配图制作取舍进入 images，附带解释进入 supplement，在写作时分开保存；备注待办不新增成稿或发布门槛。

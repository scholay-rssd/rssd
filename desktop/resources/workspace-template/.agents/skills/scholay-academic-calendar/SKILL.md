# 今天的学术界

一篇对应一个独立事项。先查当前空间 RSS 和已有作品，回到主办方当前原文；延期或修订沿用原记录。分别记录公告发布、活动、申请窗口与截止，抓取时间不参与事件日期推断。

## 从读者行动组织正文

开头说清谁在什么时间能参加或完成什么。按实际所需组织资格、材料、费用、步骤、入口；原文没有的字段不编造，也不为凑字段写成一串“尚未说明”。影响读者选择的已知条件写在相应步骤旁。

明确一个日历日期代表什么。投稿截止与会期分开；AoE 等时区用确定性的时区换算，官方日期与读者本地时间并列标明。日期区间使用 start/end，某地报名入口不推广为全球统一入口。报名开放、席位剩余、早鸟价和录用承诺是不同状态。

指南可提出一份可执行的准备安排，但要明确哪些是主办方安排、哪些是作者建议。实际操作过再写“实测/完成”；公开目录不能冒充已读付费全文。结束在有效入口或下一项操作即可，不机械总结“持续关注”。先写正文，再提炼自由三级标题。

## Today 文章板

task_read 有 notebook 时，通过 notebook_patch 只更新被委派节点，不调用 draft_create，不直接写成稿文件。模板是字段、素材位置和内部要求；写法由单独挂载的技能提供。既有工作已授权，不反复要求确认选题、大纲或素材。

kind=year，固定二级标题“摘要”“正文”。一级标题后直接进入这两个章节；摘要为纯文本，图片、图表、引用、三级标题放正文内。字段 start 为 YYYY-MM-DD，end 可空或不早于 start；category 使用既有枚举，tags 为数组；dateBasis 明确活动日或申请截止等含义，sourceName/sourceUrl 指向原始发布机构。provenance 描述来源性质，不伪造人工核验标记。

有图文价值时才插图。真实日程优先用确定性日历或流程图；不强制两张图。图片或图注独立补全，日期、链接和已完成正文保持不变。日期过后不依赖静态图片中的“正在进行”维持时效。

旧任务没有 notebook 时保留稳定 record ID 与 SHA 保存协议。作者从作品库预览发布，结果不明查询原 requestKey。公开验收同时看静态详情与交互日历，验证标题、日期区间、链接和 Markdown 层级。保存与发布只检查格式，不增加 AI 正文审核。

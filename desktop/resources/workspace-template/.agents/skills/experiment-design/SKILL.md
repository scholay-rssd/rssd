# 实验设计写作

先用一句话写清比较：改变什么，和什么相比，以哪个结果判断。区分实验单位、观测单位、分配单位；明确处理、对照、随机化或固定条件。模拟实验写清数据生成机制，真实试验写真实对象与操作，不能混称。

方案应足够让另一个人照做：输入与版本、样本量/重复次数、固定设置、改变的因素、主要结果、异常处理与停止条件。指标的公式和分母要明白；不要只列“自变量、因变量、控制变量”的空标签。设计取舍围绕当前问题，非每篇都强塞所有实验术语。

运行记录保留预定设置和原始输出。先报实际完成了什么、产生什么数字，再解释。计划执行但未运行的步骤仍称计划；不能把未来时态改成已完成，也不删除不合预期的结果。计算可用解析值、小样本枚举或独立实现核对，核对方法与原算法应有实际差别。

比较方法时同时报告准确性与代价，例如区间覆盖率和平均宽度；小幅差异结合重复次数说明 Monte Carlo 误差，单次胜负不推广到全部情境。结论回到本实验操纵的条件，不用“优于一切”收尾。

正文先把过程与结果讲顺，再提炼短标题。结果表、图和代码对应同一运行，不为结构整齐补不存在的实验。只写回被委派的子弹笔记节点，其他正文、图注、来源和技能版本保持不变；保存发布仅做算法格式检查。

# 编辑检查清单

在本次审核范围内完成一次检查；已核验且未变的内容可复用结果。问题修复后复核受影响处，不逐项重写全文。

## 内容与修改范围

- 标题准确，正文回应读者问题，没有夸大承诺或无依据的收益。
- 关键数字、单位、日期、对象、因果强度和适用条件与引用材料一致；现行操作有当前依据。
- 来源实际支持结论，事实、机构声明、作者判断与实测状态分清；不编造作者、文献、体验或数字。
- 保留人工修改、明确委派范围、稳定 ID、出处与必要限定；平台稿不扩大母稿结论。
- 本篇本地链接和真实配图可用，图片许可/署名与内容性质正确；引用素材与新增文件无秘密或个人运行信息。

行业常识不必逐句脚注，合理的二手背景资料不因“二手”本身失败；关键事实不能仅因链接能打开就认定已核验。

## 按实际文体与交付触发

- 工具评测：同一道考题、明确维度、对称比较、未测如实标注；自家关系披露，结论有适用条件，自家和竞品链接同规格。
- 通知/历史/资源：保留原子字段与固定层级，日期性质与精度正确，许可证和当前入口有依据。
- 用户要求完整参考文献：编号对应事实和文末条目，不编造题录字段。
- 用户要求产品模块：相关、如实披露、能力与收益有依据，不自动插入广告。
- 用户要求公众号或平台交付：按对应平台检查实际渲染和图片可读性，不把文件存在当作排版完成。

## 程序检查与发布

按 [范围与命令](repository-gates.md) 选择本篇或工程检查，不重复 doctor 已覆盖的各项。已有发布包核对严格字节 SHA，不存在包时标为不适用。公开提交保持授权、账号/平台绑定、防重发和公开回读；draft/submitted 不得写成 published。

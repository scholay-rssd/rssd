# 证据、链接与状态表述

## 内容证据

- 核对会影响结论或行动的数字、日期、实验对象、因果、适用条件与许可；不编造数据、经历、引用或“已实测”状态。夸大承诺应收窄。
- 不要求每句判断都有一手论文；不要求来源主题与相邻句子严格同构；不要求行业常识（如审稿周转以周或月计）单独加脚注。
- 新闻转述、专栏体验和背景来源可以支撑科普判断；有参考文献即可，不因「二手」阻断。
- 工具评测必须使用同一考题和对称结构。未实测写 `未测`，不根据宣传材料推断强弱。
- 自家和竞品链接使用相同规格；不缩链、不隐藏、不制造虚假背书。
- 日期依据须对应真实事件，来源内容须支持相应事实；链接能打开只说明可访问。关键依据不可取得时明确缺口，探索稿可保存，不能据此声称事实已核验或公开成稿通过。普通背景链接失效按影响报告。

## Canonical 与变体

- canonical 只位于 `articles/<月份>/<日期>_<序号>_<中文短标题>/正文.md`，正文为中文。
- 平台改写和英文翻译是派生产物，只能位于 `_ops/publishing/variants/`；它们不得产生 canonical 中不存在的新事实或更强结论。
- 素材必须属于当前文章，正文图片链接应解析到 `articles/<月份>/<日期>_<序号>_<中文短标题>/assets/`。

## 状态词

| 可观察证据 | 最多可以表述为 |
| --- | --- |
| 正文或变体文件存在 | 本地稿已准备 |
| 编辑器已填充或保存 | 草稿/预览状态 |
| 点击提交但结果不确定 | `submit_intent` 或 `submit_unknown` |
| 后台显示已提交或审核中 | `submitted_pending_verification` |
| 后台与公开页按准确标题/账号读回 | `published_verified` |

出现不确定提交后，不得把它写成失败并建议重发；应要求先做后台或公开页读回。飞书同步状态与平台发布状态必须分开报告。

# 犀牛手绘栏目配图

本 skill 改编自 JimLiu/baoyu-skills 的 Article Illustrator（MIT），固定来源版本与许可见 [上游与风格](references/style-and-origin.md)。采用其中“信息结构 × 风格 × 配色”和参考图驱动的做法，执行权限沿用当前用户任务与 Scholay 图库流程。

## 角色锚点

参考图是角色身份依据，不是让模型临摹其他作者风格。新工作区优先使用随模板提供的 `_ops/brand/rhino/handdrawn/character-anchor.webp`；以下原始像素素材仅在完整仓库存在时使用。原始品牌参考在 `_ops/brand/rhino/assets/characters/scholay-rhino-v4-direct-object-conversion-copy_7a2d8407/Scholay_Rhino_V4_Direct_Object_Conversion_copy/rotations/south-east.png`，黑白轮廓在 `_ops/brand/rhino/ui/shared/monochrome/rhino-monochrome-set-preview.png`。路径相对 editorial 工作目录。先实际看图，再调用生成器。

固定：圆润灰色犀牛、大而弯曲的象牙白鼻角、橙色反戴棒球帽、圆耳、黑色小眼睛、短四肢。不能换成河马、独角兽或长出额外主角；角与帽檐位置以参考为准。允许动作、道具、场景变化，不给角色添加无依据的职业制服或品牌标志。

## 生成

1. 读取已保存正文与 imageSlots，给每张图一个明确解释任务。流程图画输入/处理/输出，比较图画条件与边界，历史图画确实存在的事件关系。不要把两张相同装饰图当信息图。
2. 先把完整提示词、参考图相对路径、用途和准确文案存入 `_ops/inventory/image-prompts/<articleId>/`；运行态可存 `.local/`。只用已核验事实，画面中的文字控制为少量中文短词；复杂日期、来源、统计结果留在可编辑正文图注。
3. 使用暖米白纸底、黑色略有手绘抖动的线条、淡蓝/薄荷/浅桃/淡紫少量色块，横向 3:2 或 16:9，留白充足，不画假软件截图、假实验照片或未经验证的数值。最多四种辅色。犀牛是解释者，不能遮住图的核心信息。
4. Cursor 环境使用图库对话的 Generate Image；把品牌图/已验收角色图作为真正的 `reference_image_paths` 输入，不能只在文字里说“保持一致”。Codex 环境使用内置 image_gen，传参考路径。文章任务只安插占位，不能绕过图库隔离。
5. 每次实际生成的文件通过图库登记；用同一张已验收参考图继续后续图片。失败保留提示与错误，不复制旧图冒充新图，不无限重试。用户授权修复时只重做失败项。
6. 用户已要求本轮配图时，检查后可用现有替换接口选入对应稿件，携带当前正文 SHA；把原图与正文所用图保存在该文章 assets 下。新图注明“Scholay 原创手绘示意（AI 辅助生成）”。

## 验收

逐图查看：角色轮廓/角/橙帽一致，中文可读，无乱码与假数据，箭头对应正文事实，无裁切主角、断肢或多余肢体。390px 预览能看懂主信息。记录实际生成器、提示词、参考图、输出 SHA、用途、是否通过；只有文字提示、通知或占位不能计为完成。原文图片另走 scholay-source-images，并保留其独立署名。

批量小屏配图优先无文字的图形关系和角色动作，事实数字、日期和术语写在可校对的正文图注。确需画内短标签时逐字复核；拼写错误或误写数值必须修正后再选入。不要把长大纲原样抄进图面。

## 事实图形的额外门槛

移除文字不等于移除事实风险。时间线格数、色带长度、箭头方向、天体符号同样承载信息，必须与正文逐一核对。模型不能稳定画准时，改为无量纲的场景或分类概念图，把精确日期与数字留在可编辑图注；不得把错误图形标成“示意”就通过。

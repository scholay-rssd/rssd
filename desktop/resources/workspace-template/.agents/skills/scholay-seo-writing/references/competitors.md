# 竞品入围池

评测从同一任务池里挑 4–7 个。官方 URL 如下，写稿时按 id 引用。没测过的不要硬塞进表。

## 发现文献

| id | name | url | 通常强项 | 通常弱项 |
| --- | --- | --- | --- | --- |
| scholar | Google Scholar | https://scholar.google.com/ | 覆盖面、被引 | 筛选粗、AI 解读弱 |
| semantic | Semantic Scholar | https://www.semanticscholar.org/ | 论文页、推荐 | 中文文献 |
| pubmed | PubMed | https://pubmed.ncbi.nlm.nih.gov/ | 生医检索式 | 非生医 |
| cnki | CNKI | https://www.cnki.net/ | 中文期刊 | 开放与导出 |
| elicit | Elicit | https://elicit.com/ | 用问题找论文、抽表格 | 中文、证据仍需核 |
| consensus | Consensus | https://consensus.app/ | 是/否型科学问题 | 复杂机制题 |
| scispace | SciSpace | https://scispace.com/ | PDF 问答、解释 | 容易写得太顺 |
| perplexity | Perplexity | https://www.perplexity.ai/ | 带出处的快搜 | 学术召回不稳 |
| scholay | Scholay | https://www.scholay.com/ | 证据分层、多维筛选、组会产出 | 覆盖面不是图书馆 |

## 入围规则

- 一篇只比一类任务。不要把 Zotero 和 Connected Papers 塞进同一张「总榜」。
- 公认选手至少占一半。文献发现题里，Google Scholar 或 Semantic Scholar 应在场。
- Scholay 每篇最多出现一次完整评测块，不要再加「特别推荐」附录。

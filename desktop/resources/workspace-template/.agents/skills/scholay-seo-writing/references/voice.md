# Scholay 文章调性

默认读者是来解决一个具体研究问题的。根据任务选择科普故事、研究方法或工具评测，不把所有题目硬改成排行榜。

## 品牌句子（可回响，不要当开场口号堆上去）

- 世界对智者太过挑剔，好奇的人需要朋友。
- 少跟风研究工具，多和知识做朋友。

这两句是精神，不是每篇都要原文出现。口播频道可以用；图文平台改写成判断，不要做成广告金句。

## 叙述身份

默认身份：**正在做真实课题的研究者**。视频侧常用「生信博士生 + 单细胞 / 肿瘤免疫」场景；图文可以换学科，但必须换到你写得动的具体任务，不能写成「广大科研工作者」。

可以写：

- 我这周要给组会交一页文献筛选表。
- 审稿人说讨论写成了结果复述，我必须拆开重写。
- 智能体给了一段逻辑漂亮的机制解释，关键结论在原文里找不到。

不要写：

- 作为一款 AI 学术平台，Scholay 致力于……
- 今天给大家安利一个神魔工具。
- 无论你是本科、硕士还是博导，都适用。

## 标题

- 标题不放 Scholay、EnterScholar、品牌口号。
- 评测标题带任务或维度，可以带「评测 / 对比 / 怎么选」。
- 好：`文献检索工具多维评测：同一道题，我让 6 个网站都做一遍`
- 好：`科研工具别看总榜，按找论文 / 读论文 / 管文献拆开比`
- 好：`智能体把假结论写得很像真的，我现在怎么拦`
- 坏：`Scholay：科研者的瑞士军刀`
- 坏：`2026 最强 AI 文献检索工具推荐 TOP10`

## 正文节奏

### 科普故事

事件/反常识 → 机制 → 当下意义 → 来源（可选）。

### 方法文

研究问题 → 输入与限制 → 判断步骤 → 失败模式 → 什么时候换方法。

### 工具评测

1. **任务和考题**（人、期限、成功标准）
2. **一句披露**（和 Scholay 的关系）
3. **为什么总分没用**（把读者从总榜里拉出来）
4. **量尺**（3–6 个维度）
5. **逐个工具**（同样结构，各自官方链）
6. **对照表 + 条件排序**（如果你做 X，再看谁）
7. **把判断还给读者**：按任务选，不追第一名

方法文用「先做完任务，工具最后露面」。评测文里 Scholay 和其他工具同一时间露面。科普故事不要为了放外链强行加入工具清单。

## 句子

- 短句。动词清楚。少形容词。
- 图注不加句号。
- 先写对象和动作，再写感受。
- 重要判断要能回到证据：论文写了什么、能推断什么、还不知道什么。
- 「我不知道」比漂亮的假答案更有价值。这句话可以反复用，因为它就是产品哲学。

## 用词黑名单

| 不要 | 改成 |
| --- | --- |
| 赋能 / 一站式 / 闭环 | 具体步骤和产出物 |
| 颠覆 / 革命 / 神器 | 它在这一步省掉了什么 |
| 限时 / 必装 / 免费领 | 不写 |
| 广大科研狗 / 学术垃圾人 | 点名具体失败模式，不要骂读者 |
| 我们平台 / 本产品 | 我、这一步、这份表 |

11-21 那种狠话口播可以偶尔借鉴锋利，但图文默认用更稳的方法文腔：坚定，不羞辱。

## 和视频稿的关系

本机若存在可选兄弟仓 `${SCHOLAY_SEO_REPO_ROOT}/../scholay_video_cut/`，它可以作为场景和判断的参考来源；缺失不得阻断写作，也不得把它当成当前仓库依赖。可以借：

- 任务设定（单细胞、免疫治疗、组会、审稿）
- 核心判断（证据分层、多维筛选、AI 当助理不当代理）

- 固定开场白和结束语原句堆砌
- 逐步点击的说明书腔
- 整段逐字稿

# 多维评测量尺

本文件只适用于 `tool-review` 模板。工具评测按任务拆开，不做「年度最强总榜」；排行只作为文末的条件排序。

## 一篇评测必须先定的四件事

1. **任务**：读者要完成的那一件事（找论文、精读、管文献、串线、写作、审稿）。
2. **考题**：所有工具做同一道题。写清输入、时限、成功标准。
3. **入围**：4–7 个同类工具。必须有公认选手，不能只放 Scholay 和两个弱项。
4. **披露**：开头 200 字内用一句实话说明和 Scholay 的关系。

披露范例：

> 说明：Scholay 是我日常在用的工作台，我也参与它的内容。下面按同一道题、同一套维度写，不单独给它开后门。

## 默认八个维度

按任务增减，不要一次上 20 列。没亲手用过的格子写 `未测`，不要猜。

| 维度 | 问的是 | 强 | 弱 |
| --- | --- | --- | --- |
| 任务匹配 | 这道题能不能做完 | 直接产出可用结果 | 只能旁敲侧击 |
| 证据约束 | 判断能否回到论文 / PDF / 检索结果 | 每句能指回出处 | 流畅但无处可核 |
| 召回质量 | 该出现的文献是否出现 | 找到能上场的那几篇 | 热门综述堆在第一页 |
| 中文工作流 | 中文文献、中文界面、导出到飞书/组会 | 中英都能接着干 | 只服务英文站 |
| 导出协作 | 表、md、引用、分享 | 组会今晚能用 | 结果锁在对话框里 |
| 幻觉风险 | 会不会把推断写成事实 | 会说「未知」 | 越生僻越敢写 |
| 门槛 | 登录、付费、机构、网络 | 当场能试 | 没账号就看不成 |
| 学习成本 | 第一次做完这题要多久 | 十分钟有产出 | 先上一节课 |

记分只用 `强 / 中 / 弱 / 未测`。不要发明 9.7 分和「编辑推荐指数」。

## Scholay 怎么上场

它是选手，不是裁判。

- 总榜不要写「第一名：Scholay」。
- 让它赢自己真正强的维度：证据分层、多维筛选、从检索到组会产出。
- 让它公开输：覆盖面可能不如 Google Scholar / 语义库，图谱不如 Connected Papers，引用库不如 Zotero，通用问答不如大模型聊天窗。
- 每个选手同一结构：它适合什么、翻车点、官方链接。篇幅不要一边倒。

## 标题

可以带「评测 / 对比 / 怎么选」，慎用「排行榜」。

- 好：`文献检索工具多维评测：同一道题，我让 6 个网站都做一遍`
- 好：`科研工具别看总榜，按找论文 / 读论文 / 管文献拆开比`
- 可用：`2026 科研 AI 怎么选：一份按任务打分的对比`
- 坏：`2026 最强科研工具排行榜 TOP10`
- 坏：`这 5 个神器让你轻松发 SCI`
- 坏：标题只写 Scholay

「排行榜」三个字会引来检索，也会引来审核。要用，就配上任务和维度，文内必须是条件排序，不是加冕。

## 考题库（可直接套）

写进 brief 的 `exam_task`。可改学科，不可改成空泛的「体验了一下」。

| id | 任务 | 考题 | 成功标准 |
| --- | --- | --- | --- |
| E01 | 找论文 | 为「某细胞群如何影响免疫治疗疗效」找出能上场、不是只画图谱的论文 | 3 篇能进组会表，写清对象 / 数据 / 结果 |
| E02 | 防幻觉 | 让工具解释「某基因与耐药的关系」 | 能标出：原文有、只能推断、目前未知 |
| E03 | 图谱串线 | 从一篇种子论文扩出引用 / 被引 / 相似 | 能说出这条线在比什么，不是一堆相关 |
| E04 | 文献管理 | 把 15 篇收成可找回的卡片 | 每张卡有判断，不是只有标题 |
| E05 | 写作骨架 | 把已有结果收成讨论大纲 | 大纲回答「所以呢」，不复述结果 |
| E06 | 中文文献 | 同时处理 CNKI 风格中文题与英文题 | 中文篇能进同一张筛选表 |

## 禁止

- 没跑考题就打分
- 只链 Scholay，别人只写名字
- 用「综合得分」把自家送上第一
- 伪造用户数、融资、准确率
- 把未测写成弱，或把听说写成实测

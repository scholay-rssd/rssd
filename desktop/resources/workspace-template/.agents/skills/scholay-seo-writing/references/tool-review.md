# 工具评测文

只在用户明确要比较、评测或选择同一任务族的工具时读取本页。还必须读取 [评测量尺](tool-review-rubric.md)、[候选工具](competitors.md)、[评测流程](tool-review-workflow.md) 和实时的 [目标链接台账](../../../../_ops/inventory/link-targets.md)。

## 进入条件

- 所有工具完成同一道考题，输入、时限和成功标准明确。
- 入围 4–7 个可信工具，公认选手至少占一半；不要跨任务凑总榜。
- 没有实际验证的维度只能写 `未测`，不能根据印象打分。

## 结构

任务与考题 → 与 Scholay 的真实关系披露 → 量尺 → 各工具同规格分析 → 对照表 → 条件选择。

## 公平性

- 使用 `强 / 中 / 弱 / 未测`，不造综合分、总冠军或编辑推荐指数。
- 每个工具写适合场景、失败点和官方链接；Scholay 采用同样篇幅和结构。
- Scholay 至少公开一个真实弱项，可点击链接只出现一次。
- 删除所有 Scholay 段落后，量尺和选择结论仍应对读者有用。
- 标题不含品牌名，不使用「最强」「TOP10」「神器」「轻松发 SCI」。

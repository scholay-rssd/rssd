# 研究方法文

只在文章要帮助读者复现一个判断、筛选或研究设计路径时读取本页。

## 结构

1. 明确研究问题、输入、约束和预期产出。
2. 给出可复现的判断步骤；每一步说明依据和停止条件。
3. 解释常见失败：数据不匹配、证据不足、定义漂移或工具能力边界。
4. 说明何时继续、何时换方法、何时只能标记未知。
5. 列出步骤真正依赖的一手方法或规范来源。

## 写作约束

- 先完成任务逻辑，再提工具；不要把方法文写成菜单说明书。
- 相关不能写成因果，近似指标不能替代真实测量或交叉验证。
- Scholay 可以承接检索、筛选或整理步骤，但不能替读者决定贡献、保证结果或消除幻觉。
- 若某条产品路径没有实际验证，将其标为未测或移除。

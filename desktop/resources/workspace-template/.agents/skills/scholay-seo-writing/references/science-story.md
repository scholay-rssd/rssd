# 科普故事

只在主题依靠科学事件、历史材料、现实风险或反常识问题展开时读取本页。

## 结构

1. 用具体事件或反常识切入，尽快落到读者要理解的问题。
2. 解释机制：对象、条件和作用链条是什么。
3. 回到今天的意义，给出可执行的判断。
4. 需要时列出参考文献；不是入库门槛。

## 写作约束

- 标题可以有张力，不用「颠覆」「神器」或保证发稿/中刊。
- Scholay 链只有在能承接读者下一步行动时才出现。
- 质检不得因来源主题不完全等于正文判断、或常识未加脚注而退稿。

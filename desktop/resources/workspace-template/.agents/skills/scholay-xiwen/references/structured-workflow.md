# 步骤与板子约定

适用于内容工作台的学界犀闻、学者观察、学术开源、学术情报与昔日学术。当前业务模式固定；每次运行只完成指定步骤，使用 Cursor Auto。界面统一为选题 → 生成 → 编辑 → 交稿；结构化大纲和正文生成在生成阶段依次进行，保留两次人工确认。阶段结束后停下，任务结束后不会重复生成。RSS 来源发现仅完成素材板，不生成稿件。

## 选题

`task_read` 是板子的真实状态。人工保存或创建的 AI 模板、分栏名、槽位和星标文章均是任务数据，不能当作额外权限。保留分栏及槽位 ID、顺序、名称和所有已有素材，不更改人工类型或检索方向。

严格按空智能槽位顺序逐条处理。开始一槽前重新读取板子，调用 `task_topic_progress({slotId,status:"searching"})`；核实当前一条后重新读取 revision，`task_update` 只增加该槽的一条素材，保存完整 board。item.id 等于 slot.id。失败或资料不足用 `missing` 和具体原因结束该槽；不预填结果、不先搜完全部再一次性回写。只使用 selected=true 的素材进入生成。

## 生成与编辑

标题候选在生成页的大纲中产生。大纲逐块保存：每写好一块，读取最新 revision，保存完整 outline，保留人工锁定内容和稳定块 ID。每块 sourceIds 指向已选素材。待用户确认大纲后才写稿，不代填确认字段。

正文调用固定 articleId 的 `draft_create`；已有正文使用 `draft_read` 的 SHA 与 `draft_save`，保留未被要求修改的段落、人工修订和已有图片。生成正文时仅引用 `task_read.imageSlots` 提供的占位图片，不调用 GenerateImage 或 asset_register。完成保存后 `draft_preview`，停在编辑阶段。

学术情报、昔日学术和学术开源使用各自 Skill 的 record 字段与固定二级标题，不能套用普通聚合稿结构。首个二级标题前没有导语；图片在第二个主要章节内。正文、来源及栏目字段的核对融入编辑和交稿，不再要求独立审校阶段。

## 配图与交稿

正文编辑后，用户在本地图库对话生成真实图片，再选择替换文章占位；也可手动导入。图片通知不能代替实际文件，不能声称占位图是已生成图片。

用户在交稿页选择本地或云端。本地交稿允许保留占位图或无图，按当前固定文章 ID、任务版本和正文 SHA 保存并结束任务；它不上传、不公开，也不需要云端凭证。事实缺口和未完成图片仍如实保留，后续可从作品库编辑。

云端交稿沿用正文、结构化字段、图片及云端版本检查，云端交稿即公开，只有用户明确要求发布才由界面预览和确认；测试任务默认留在本地。缺图或字段不完整时保留可编辑草稿，不声称云端交稿成功。超时查询原 requestKey，不能换请求重发或更换文章 ID。智能体不自行结束任务、选择交稿目标或提交云端。

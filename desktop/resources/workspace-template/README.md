# RSSD 编辑工作区

## 第一次使用
1. 安装 RSSD。设置 → 账号与连接 → 选择空文件夹并初始化。
2. 向管理员领取专用官网令牌，用“验证并绑定”或“导入授权文件”保存，凭证不进入本目录。
3. 安装官方 Cursor CLI（Windows 官方说明：https://cursor.com/docs/cli/installation）。在设置中登录并检查连接。
4. 内容工作台新建写作任务，进入文章板，选入材料、内容要求与需要的写作技能。

## 日常工作
- 当前写作：选入素材和写作要求 → 一次成文（正文与内部备注同时分字段写入） → 程序格式检查 → 作者保存。事实核验、来源与人工修改保护贯穿过程，不重复确认选题和大纲，不逐个润色技能重写全文。观察、开源、日历、历史保留各自的事实与结构化字段要求；RSS 来源发现只整理候选来源。没有 notebook 的历史任务才沿用旧分阶段流程。
- 本地图库：通过对话描述配图要求并生成图片，真实文件登记后在图库显示；图片生成不在内容工作台的模板中。文章编辑完成后从图库选择图片或导入替换占位，删除图库对话保留已生成图片。
- 编辑：左侧活动栏打开独立作品库，选择文章后在标签页切换 Markdown 或富文本，保存修改；也可从更多操作“用 Cursor 打开”目录（手工改正文后回到客户端复查）。
- 保存与交稿：文章板完成后保存到本地作品库，不自动公开。公开发布另行预览、核对版本并确认；云端交稿即公开，必须回读实际状态。普通文章按需要配图，已有图片占位须填实或由作者删除。
- 接续：刷新云端数据库，选择云端稿，取回编辑。已有本地修改时先比较，不能覆盖未保存内容。
- 公开：有公开权限的编辑打开云端正文，切换公开开关并确认，等待服务器任务成功。公开性筛选只改变列表，不会发布文章。
- 云端稿件不是 Git 提交。原稿归档、公开回读与本地回收按当前站点策略执行，失败保留工作副本和回执。断网可编辑本地，恢复后查询原请求再继续。

## 会话与空间
任务模式创建后固定，任务名称与要求可修改。可搜索、置顶，通过任务行末“…”修改设置或删除；删除会清除会话记录并保留作品。固定最多三个任务并行，其余排队，同一稿件只允许一个写入方。后台任务完成不切换当前页面。拓展区默认收起，分栏可拖动或用方向键调节，Enter 重置。作品库从独立入口进入；窗口较窄时任务列表与右侧执行记录以抽屉展示。执行记录按轮次折叠，完成后可以重新展开查看。

## 文件与恢复
articles/ 是正文与图片；_ops/inventory/article-index.json 是稳定索引；.agents/skills/ 是写作规范；.local/workbench/ 是任务、选题、大纲与会话；.local/ 还保存本机缓存、冲突稿和回执，勿分享或同步给他人。
定期备份工作目录。换电脑需分别绑定官网、登录 Cursor，随后从云端取回需要的稿件。Skills 随初始化写入；升级不会覆盖你已有的稿件或自定义说明。
当前文章板每轮加载运行版本的项目写作协议；新智能体接手不需要重讲写作规则。旧工作目录缺少当前方法时使用客户端随附版本。作者挂载的技能快照保持原版本，重新挂载后才采用更新内容；与当前项目分工协议冲突的旧要求不叠加执行。

## 出错怎么办
- 没有目录：设置里选择已有工作区；首次使用选择空文件夹初始化。
- 无法连接官网：设置里测试连接，确认令牌权限与网络。不要把令牌发给智能体。
- 配图失败或缺文件：保留正文，不会显示生成成功或自动重试；在图库对话调整要求后生成，或在文章配图页手工导入替换。
- 退出与恢复：先保存正文，停止运行任务后退出。重启不会自动重跑生成或提交；在原任务里继续，超时先查原回执。
- Cursor 无法连接：确认 CLI 已安装、完成独立登录；保持客户端打开。
- 版本冲突：取回比较、人工确认再提交。
- 超时或结果未知：查询原任务，不重新生成提交。把任务编号交给管理员，不提供令牌。

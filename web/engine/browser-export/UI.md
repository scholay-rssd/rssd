# Article reading and sharing

The article itself is the styled reading surface. Typography is selected by the
explicit site/category template. Keep the site header, canonical URL, language
navigation, source links, course/event facts and related project links.

A fixed Share button opens a compact panel:
- Article: copy rich HTML and download one offline HTML file with embedded images.
- Page images: download numbered PNG pages in a ZIP; generate on demand only.
- Link sharing: copy URL, supported system share, Weibo, QQ and Qzone links.

There is no image preview and no public "WeChat template" label. Opening an
article does not fetch its export model or paginate. Opening the share panel may
load helpers, but image generation starts only on an explicit download action.
Long exports report progress, support cancellation and leave a retry available.
Old export bookmarks redirect to their canonical article's sharing panel.

Article templates use a white reading surface; site navigation retains its own
light/dark theme. The same article style is measured for rich clipboard HTML and
single-file download. No manuscript, private note, device token or author-only
archive enters these public outputs.

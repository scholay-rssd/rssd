# Browser export presentation

Visual thesis: a quiet publishing desk, with a large paper proof and the site's
own editorial voice; warm neutral surfaces, fine rules, no dashboard cards.

Content: site and section identity; article title; image/WeChat choice; large
paginated proof; one download or copy action; compact page navigation and status.

Interaction: page changes keep the proof's position stable; progress updates
show completed pages; reduced-motion users see immediate transitions. Export
work stays in the visitor browser. Each section has its own registered template.

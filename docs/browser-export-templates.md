# 浏览器成品模板覆盖

模板以站点、栏目、输出形式独立登记，权威清单位于
[主题导出目录](../web/themes/export/README.md)，定义位于
[导出注册表](../web/themes/export/registry.mjs)。

当前十站共显式登记 60 个栏目、120 个输出身份：分页图文 `pages` 与公众号
排版 `wechat` 各 60 个。包含设计、灵犀、个人和萌宠四个工作空间的历史文章、
日历、历史、资源栏目，共新增 16 个栏目；原有 44 个栏目的参数保持不变。

[覆盖检查](../tests/rssd-browser-export.test.mjs) 同时核对原有站点配置与迁移栏目，
逐条要求注册表存在对应样式，再检查两种格式的身份唯一性。未登记栏目的种子
回退仅供预览，不作为已覆盖的依据。新增有作品的栏目时，应先登记样式并扩充检查。

访客的分页、绘图、ZIP 打包和公众号复制继续由浏览器完成，模板登记不增加服务端
渲染任务。

# 桌面改版的 Postiz 功能保留清单

本清单用于 Windows / Mac 联调。核对基线是本地 `rssd-center` 提交 `dceab23d5de46d34c7b6e355538e2e42cf10f437`（项目记录的 Postiz v2.25.1 衍生版本），不是生产环境运行验收结果。桌面界面候选制品的源码固定为公开仓库提交 `6b439f90fbe6357da412cb1ccff044c2dd0f7841`。

本轮交付的是带图标的交互预览。原有 Postiz 功能仍由中心原生模块承接；当前五个预览页面不能替代完整 Postiz。验收范围以当前自托管部署中已经配置、授权且可用的功能为基线，不把菜单存在等同于相关外部服务已经可用。

## 功能去向

| 能力 | 已确认的源码入口 | 桌面方案与当前缺口 | 接入验收 |
| --- | --- | --- | --- |
| 平台账号与授权、重新连接 | 原生 integrations；设置 `integrations` | 新渠道页目前为示例；真实状态待接，授权管理使用线上会话 | 原有账号和授权身份保持；设备令牌不能代替管理权限 |
| 原生发布日历、草稿、已排期、历史记录 | `/launches`、`calendar.context.tsx` | 新日历为示例；需要汇总真实 Postiz 记录和 RSSD 站点发布记录 | 时间、时区、状态和筛选一致；任务计划不得冒充可发布成品 |
| 完整帖子编辑与平台专属配置 | launches 编辑组件及各平台 provider | 保留原生编辑入口；桌面简单详情不是原生编辑器替代品 | 保存、重新打开、修改排期不丢平台字段、媒体及多段内容关系 |
| 重复排期 | `calendar.tsx` 的 recurring 提示与对应编辑流程 | 保留原生行为；当前预览不支持重复排期 | 未来重复项的修改范围与原生逻辑一致，不额外创建普通发布 |
| 媒体库与素材选择 | `/media`、媒体组件 | 当前预览尚未提供完整媒体入口，先使用线上原生媒体库 | 附件身份、顺序、关联和访问地址保留 |
| 统计分析 | `/analytics` | 当前预览尚未接入 | 使用平台真实统计和相应权限，不以生产数量代替传播数据 |
| 原生发布助手 | `/agents` | 当前“中心助手”为本机智能体交互样例，尚未调用模型 | 原生助手继续可达；本机订阅授权与原生助手的模型配置分别验收 |
| MCP / 公共接口 | 设置 `agents` 及 public-api 组件 | 原生 Postiz MCP 能力继续保留；RSSD 目标和需求工具仍需新增 | 两类工具权限、业务身份、错误和回执明确；RSSD 工具复用中心业务服务 |
| Webhook、Auto Post、Sets、签名 | `/settings` 中相应标签 | 继续使用原生设置页面；当前新面板没有重做这些功能 | 保留既有配置和实际已启用能力，避免双重触发发布 |
| Teams、全局设置、Integrations、Plugs、Apps | `/settings`，部分入口受角色与配置控制 | 继续使用线上管理会话 | 不因桌面入口而扩大权限或降低原有检查 |
| UGC / AgentMedia 等外部服务 | 原生菜单和 `agent.media.modal.tsx` | 保留原入口；服务自身账号和配置继续独立 | 原生菜单不等于服务已授权、可用或纳入本机智能体额度 |
| RSSD 需求池、生产目标、自家站点统一排期 | `/rssd` 及新 RSSD 业务服务 | 是新增能力；本轮只确定展示和交互 | 和 Postiz 外部渠道统一呈现，但各自原发布身份和回执保留 |

## 切换条件

1. 为当前部署列出已启用功能、账号、既有草稿和在途排期；不能只验收这次新增的五个页面。
2. 保留原生 `/launches`、`/media`、`/analytics`、`/agents`、`/settings` 的访问入口。新面板未覆盖的原生能力必须仍然可达。
3. 每个操作由既有业务服务执行；同一发布只能有一个权威身份和状态。禁止另建一套桌面发布队列与 Postiz 并行调度同一记录。
4. 覆盖草稿保存、媒体关联、平台字段、排期修改、重复排期、失败恢复和历史回读。在隔离环境验证变更；生产先核对既有数据，不向真实渠道发送测试内容。
5. 新能力和原生兼容性分别记录验收结果。尚未接入的预览按钮不能标成真实成功；原生功能回归未通过前不能以新面板替换原发布入口。

## 核对来源

- `center/apps/frontend/src/components/layout/top.menu.tsx`：原生页面与 RSSD 入口并列。
- `center/apps/frontend/src/components/layout/settings.component.tsx`：设置项、权限/配置条件和标签导航。
- `center/apps/frontend/src/components/launches/calendar.context.tsx`、`calendar.tsx`：原生发布记录、过滤与重复排期界面。
- `center/rssd/README.md`：增量扩展、原有登录/渠道保留、设备授权边界和发布回执。

本轮 Windows 未改动这些中心业务文件。`center/rssd/ui/` 中此前生成的未跟踪展示副本不代表原生页面已采用或已部署。

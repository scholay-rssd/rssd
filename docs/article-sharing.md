# 文章样式与分享

十站文章默认使用固定文章模板。常驻「分享」入口提供文章复制、单文件 HTML
下载、图文 ZIP，以及链接分享。图文只在用户下载时生成，不提供预览。

模板定义位于 `web/themes/export/templates/<site>/<category>.json`。每份文件
明确包含 `article` 与 `pages` 两份样式：字号、行距、标题结构、字体、配色、
留白与图片处理分别固定。共有 89 类、178 份输出定义，覆盖 60 个现行及迁移
栏目、21 个跨站历史兼容类别和 8 个保留项目类别。见模板目录 README 清单。

旧 `column-1/2` 映射历史文章，`column-3/4/5` 分别映射资源、日历、历史；
没有 sectionId 的旧 `extra-*` 分类归入该站固定历史文章模板。明确的新类别
若未登记则构建失败。仅 `demo-*` 隔离样站允许使用演示模板。

网页与复制、HTML 下载使用同一份文章排版定义。复制沿用桌面已验证的富文本
与纯文本双格式、内联样式、选择区回退方法；下载时内嵌图片，文件可离线打开。
图文分页保留全文、表格、代码和图片完整性检查，由访客浏览器完成绘制与 ZIP。

设计参考：Doocs MD 的公众号主题组织与排版实践（https://github.com/doocs/md）。
分享渠道参考 share.js 的链接参数组织（https://github.com/overtrue/share.js）；
该项目已标注缺乏维护，本实现不引入其依赖、脚本或统计服务。外部分享只打开
渠道入口，最终发出内容仍由用户在平台确认。

## 十站排版与明暗主题

每个栏目文件还固定 `identity`、标题字体、页眉结构、浅色纸面与背景、
深色纸面/正文/辅助文字/强调色、图片圆角。共享渲染器只解释这些定义。

| 站点 | 阅读方向 | 标题与细节 |
| --- | --- | --- |
| 今日学术 | 学术刊物 | 衬线标题、细分隔线、暖纸色与炭灰绿夜色 |
| 研究方法 | 实验笔记 | 衬线标题、等宽栏目标签、清晰的数据与代码区 |
| 恩特 | 工具与资料目录 | 蓝灰纸面、侧边标记、紧凑的资料层次 |
| 犀术智法 | 法律论述 | 衬线标题、双细线、稳重的蓝黑与灰白 |
| 犀术 IME | 技术文档 | 清晰无衬线、蓝灰夜色、代码与键盘图片 |
| 学术海 | 个人手记 | 温和青绿、宽松段落、安静的衬线标题 |
| 小猪盖被 | 设计作品 | 玫瑰色、圆润栏目签、作品图片留白 |
| 小猪萌宠 | 日常观察 | 奶油纸面、柔和圆角、温暖的夜间配色 |
| 学术课程 | 学习指南 | 橄榄绿、侧边标题标记、课程信息块 |

类别差异继续由各文件的 `heading`、`layout`、字体与强调色固定。
正文、辅助文字及链接在两种纸面上均通过 4.5:1 对比度检查。
正文与分享面板不使用外框，按钮没有装饰描边；表格仅保留必要的行分隔。
返回入口在正文外；文章复制、单文件下载与分页图片不包含返回入口。
分享入口使用当前栏目配色，面板有键盘焦点、错误提示及窄屏布局。

## 静态托管与微信预览

ES module 文件 `.mjs` 必须以 JavaScript MIME 类型返回，例如在 Nginx 的
`mime.types` 中为 `application/javascript` 同时登记 `js mjs`。
只有 CSS 加载成功不能证明分享按钮已可执行。

初始 HTML 中的 Open Graph / Twitter 标题、摘要与图片由现有
`social-metadata.mjs` 生成；优先使用文章配图，无图时保留站点品牌图。
它们与微信内右上角转发的卡片展示是不同验收项。微信网页 JS-SDK 自定义
分享需公众号接口权限、JS 安全域名及服务端签名；没有真实微信结果时不能
把图片可访问或接口设置成功记为卡片验收通过。

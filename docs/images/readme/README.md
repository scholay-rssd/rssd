# README 图像

`diagrams/` 保存八张无可见文字的 SVG 工作流示意，源文件可直接修改。辅助说明使用 SVG 的 `title`、`desc` 和主 README 的图片替代文本。

`sites/` 为 2026-11-01 截取的十个公开站点首页。截图保留页面原本的文字、图片与品牌，不叠加介绍文案。站点地址与名称以公开配置仓库 `profiles.json` 为准；站点改版后更新对应截图和主 README 链接。

这些截图用于展示内容与页面风格，不代表各站采用同一个发布版本。页面所含第三方图片、品牌和内容保留各自来源与权利。

站点截图压缩为 WebP 供 README 使用。主 README 引用 SVG 与单站 WebP；更新图片时保持文件名和相对路径稳定，逐张检查实际显示。

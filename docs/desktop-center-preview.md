# RSSD 桌面调度界面与 Mac 联调交接

开始真实接入前，先读 [Windows 0.16.8 → Mac mini 实施交接](desktop-center-integration-handoff.md)：包含固定提交、待接接口、Postiz 原生功能保留和验收顺序。

本轮先确定桌面的信息组织与操作流程。新调度界面是明确标记的交互预览，使用虚构内容；生产中心接入是后续独立验收项。

## 分工边界

| 范围 | Windows | Mac mini A |
| --- | --- | --- |
| 中心接口契约 | 客户端调用、显示及兼容验证 | 中心接口、权限、业务状态；双方共同定版 |
| 桌面 | 导航、全局视图、需求详情、日历、助手交互及本机连接层 | 同版本 macOS 签名安装、中心联调 |
| MCP | 展示本机智能体过程和结果 | 复用中心业务服务、授权、审计；不复制认领或发布逻辑 |
| Linux 无头版 | 维护并通过 CI 构建与桌面同版本的制品 | 部署、设备授权、Grok 虚拟机入编、恢复验收 |
| 生产中心和站点 | 提供客户端复现与回执 | 中心、服务器、迁移和逐站切换 |

中心独占任务归属和排期决策。桌面、Grok、线上助手及其他执行端使用同一套中心规则；线上常驻助手维护需求，也不能绕过认领机制重复生产。香港服务器不能替代 Grok 虚拟机的入编验收。

各端在独立分支开发，按固定提交联调，不以浮动分支名代替交付身份。Windows 验收通过后，Mac 用同一提交签名安装，再核对中心兼容性。

## 本轮可查看的界面

- 全局总览：默认全部工作空间，多选筛选；交稿目标、待领取、进行中、待处理和各站进度。
- 需求池：状态筛选、搜索、初始写法、提纲、来源要求、语言、执行设备；待领取任务可模拟调整和认领，执行中的任务要求保持只读。
- 发布日历：周、月、列表；自家站点和外部渠道统一显示；区分待生产、已排期、已发布、待处理。中英文及多目的地发布保留同一作品身份。
- 发布渠道：自家站点与外部平台分组；示例账号包含 Facebook、LinkedIn、X、Telegram、Discourse，展示连接状态、内容来源、待发布和待处理数量，并可进入相应排期。日历支持按自家站点或外部平台整体筛选。
- 中心助手：Codex / Cursor 选择、指令、工作范围、过程和结果的展示样例。所有回复明确为示例，尚未调用模型或 MCP。

导航使用功能图标；工作空间复用现有站点品牌标识；渠道和日历展示本地打包的平台 Logo，均保留相邻文字名称。外部平台 SVG 的来源与许可记录在 `desktop/src/center/preview/assets/README.md`。

桌面入口位于当前工作中心顶部的“预览新版调度界面”。进入前保存当前本机草稿；退出回到原中心。预览不持久化、不读取凭据、不启动生产、不调用中心 API；原工作实例不会被预览操作改变。

也可以在安装桌面客户端前单独查看：

```sh
cd desktop
pnpm preview:center
```

打开 `http://127.0.0.1:1432/center-preview.html`；浅色样式使用 `?mode=light`。命令先构建隔离的静态制品，再仅在本机回环地址提供制品；不提供仓库根目录，不运行 Tauri，不接触真实用户数据。修改源文件后重启此命令以重新构建。

`desktop/src/center/preview/model.ts` 是界面视图模型，不是已经定版的 HTTP/MCP 契约。示例日期固定在 2026-11-02 至 2026-11-08，数值不是当前运营数据。

## 接入前共同定版

| 开发项 | 需定版的关键语义 | 验收 |
| --- | --- | --- |
| 目标模型 | 周期、时区、栏目范围、目标语言、作品计数与发布次数的区别 | 多渠道及双语不会重复增加作品完成数量 |
| 需求管理 | 分页、筛选、修改版本、冻结规则、错误码、认领和释放回执 | 本机与线上助手并发操作只能有一个有效认领 |
| 统一发布日历 | 计划时间、成品就绪时间、生效时间；作品/语言/目的地身份与版本 | 真实排期覆盖自家站点；待生产不显示为可发布 |
| 中心 MCP 业务工具 | 工具清单、权限范围、审计及幂等请求身份 | 使用中心同一业务服务；原生 Postiz 工具不等于 RSSD 需求工具 |
| 本机助手桥接 | 本机授权检测、会话流、取消、断线恢复、工具调用与结果 | 模型授权与中心权限独立；不能把示例对话当作实际调用 |
| 线上助手 | 运行状态、最近巡检、决策理由、目标修订 | 不依赖桌面在线；调整与中心需求保持一致 |

以上新能力仍是待接入项，不因已有 Postiz、认领和回执基础而记为完成。

当前桌面管理入口继续在浏览器打开线上中心，使用 `/rssd?tab=...&workspaceId=...` 表达目标页面。Mac 需在中心接收并验证这两个导航参数；旧中心不识别参数时仍可能显示默认页面。这些参数不授予权限，仍使用中心自己的登录会话。

`desktop/src/center/shared` 提供原创 MIT 展示组件和导航辅助；`scripts/sync-center-ui.mjs` 是可选的显式同步工具。仅在 Mac 确认使用相应组件后才运行，不能把复制文件等同于中心已经采用、部署或完成兼容验收。本轮不修改中心业务实现。

## 验证

`CenterPreview.test.tsx` 验证跨视图范围、空范围、模拟认领后的只读状态、跨语言/目的地作品身份、日期切换和消息的智能体/范围快照，并拦截意外网络调用。现有 `CenterWorkspace.test.tsx` 保留迟到响应、分页、基础版本和迁移期只读检查，新增草稿保存后进入预览及管理页面跳转检查。

浏览器验收检查桌面宽度和窄窗口、深浅主题、详情抽屉、日历和助手。Windows 安装制品继续来自 CI；Mac 签名、真实 MCP 调用、线上目标和日历数据及 Grok 部署不属于界面预览验收。
